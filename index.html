This project is the practical backbone of a course on Retrieval-Augmented Generation (RAG) — teaching students how to move beyond simple chatbot prompting into building real AI pipelines that retrieve, rank, and reason over their own document collections.

🌿 What Is RAG?

Large language models are powerful, but they can only reason over what they were trained on. Retrieval-Augmented Generation solves this by giving the model access to a curated knowledge base at query time — fetching the most relevant documents before generating an answer.

This project builds that system end-to-end: from raw documents through vector indexing, semantic search, and reranking, to a final grounded response. Every component is visible, explainable, and owned by the student.

🔁 The Two Pipelines

The architecture splits cleanly into an ingestion pipeline (run once, or on updates) and a query pipeline (run at inference time). Students build both.

Sample: Loading & Indexing Documents

# ingest.py — Build the FAISS index from source documents
from langchain_community.document_loaders import DirectoryLoader
from langchain.text_splitter import RecursiveCharacterTextSplitter
from langchain_huggingface import HuggingFaceEmbeddings
from langchain_community.vectorstores import FAISS

# 1. Load documents
loader = DirectoryLoader("./docs", glob="**/*.txt")
documents = loader.load()

# 2. Chunk into overlapping segments
splitter = RecursiveCharacterTextSplitter(chunk_size=500, chunk_overlap=50)
chunks = splitter.split_documents(documents)

# 3. Embed and index
embeddings = HuggingFaceEmbeddings(model_name="all-MiniLM-L6-v2")
vectorstore = FAISS.from_documents(chunks, embeddings)
vectorstore.save_local("./faiss_index")

print(f"Indexed {len(chunks)} chunks → faiss_index/")

📚 Course Modules

This project supports a structured sequence of learning objectives, moving from concept to working code:

  • 01
    RAG Concepts & Architecture Why retrieval matters, how it differs from fine-tuning, and the anatomy of a RAG system.
  • 02
    Setup Docker Model Runner & Python Virtual Environment Installing Docker Model Runner, Managing & Using Models, and setting up a Python Virutal Environment
  • 03
    Data Conversion: Document Preparation & Chunking Loading source files, choosing chunk size and overlap, and understanding the tradeoffs.
  • 04
    The Data Ingestion Pipeline What embeddings represent, how cosine similarity works, and building a FAISS index.
  • 05
    The Query Pipeline The Query Pipeline: Retrieve chunks, Construct the Prompt, Call LLM for Answer.
  • 06
    Query Pipeline Application Demo Combine User Prompt with Context from Uses Data to Answer Questions
  • 07
    Local vs Cloud RAG: Tradeoffs and Real World Cases Token Cost, Local Memory Cost, and Hallucinations

🌱 Learning Outcomes

By the end of this project, students will be able to:

  • ✓
    Explain the difference between parametric and non-parametric knowledge in LLMs.
  • ✓
    Build a working ingestion pipeline that converts documents into a searchable FAISS index.
  • ✓
    Write a query pipeline that retrieves, reranks, and generates grounded answers.
  • ✓
    Run an open-source LLM locally using Docker — no API keys, no cloud costs.
  • ✓
    Debug common RAG failure modes: retrieval misses, hallucinations, and prompt issues.
